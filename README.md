## เป้าหมายของโปรเจกต์

โปรเจกต์นี้ใช้โมเดล Machine Learning เพื่อทำนายผลตอบแทนทางการเงินในอนาคต (ช่วง 10 ปีหลังเรียนจบ) จากการตัดสินใจเลือกเรียนต่อมหาวิทยาลัย โดยสิ่งที่เราต้องการทำนาย (ตัวแปร Y) คือ:

- **`earnings_10yr_usd` (รายได้รวม 10 ปี):** จำนวนเงินรวมที่หาได้ในช่วง 10 ปีหลังเรียนจบ

## การเปรียบเทียบโมเดล (Model Comparison)

1. **Multiple Linear Regression (MLR):** โมเดลสมการเส้นตรงมาตรฐาน (เรียบง่าย เป็น Baseline พื้นฐานในการวิเคราะห์ความสัมพันธ์ของปัจจัยต่าง ๆ)
2. **Multiple Linear Regression with Log Target (MLR + Log y):** โมเดลสมการเส้นตรงที่แปลงตัวแปรตามเป็น Log ($\log(y)$) เพื่อแก้ปัญหาการกระจายตัวของรายได้ที่เบ้ขวา (Right-skewed) โดย**จำเป็นต้องนำ Smearing Factor (Duan's Smearing Factor) มาคูณชดเชยหลังจากแปลงค่ากลับด้วย Exponential ($\exp$)** เพื่อแก้ปัญหา Retransformation Bias ช่วยให้ค่าทำนายรายได้จริง ($y$) หลังแปลงกลับมีความถูกต้องและตรงกับความเป็นจริงมากขึ้น
3. **Random Forest Regression:** โมเดลป่าสุ่ม (ซับซ้อน คำนวณเยอะ แต่ดักจับแพทเทิร์นข้อมูลแบบ Non-linear ได้ดีเยี่ยม)
4. **K-Nearest Neighbors (KNN) Regression:** โมเดลหาเพื่อนบ้าน (ใช้ระยะทางหาคนที่โปรไฟล์การศึกษาคล้ายเราที่สุดมาพยากรณ์)

**เกณฑ์ที่ใช้ในการประเมินและเลือกโมเดล:**

- **ความแม่นยำ (Accuracy & Error):** พิจารณาค่า MSE และ RMSE จาก 5-Fold Cross-Validation ว่าโมเดลไหนทำนายได้ใกล้เคียงของจริงที่สุด
- **ความคุ้มค่าด้านทรัพยากร (Resource Efficiency):** หากโมเดลที่คำนวณไม่ซับซ้อน (เช่น Linear Regression) สามารถทำนายได้แม่นยำเทียบเท่าหรือใกล้เคียงกับโมเดลที่ซับซ้อน/กินทรัพยากรสูง (เช่น Random Forest) เราสามารถพิจารณาเลือกใช้โมเดลตัวเล็กกว่าได้ เพื่อประหยัดเวลาและทรัพยากรในการประมวลผล

## ข้อมูล 1 แถว สื่อถึงอะไร?

ข้อมูลแต่ละแถวในชุดข้อมูลนี้หมายถึง **"ข้อมูลของบัณฑิต 1 คน"** (รายบุคคล) ไม่ใช่ข้อมูลภาพรวมของคณะหรือมหาวิทยาลัย
โดยแต่ละแถวจะบอกเล่าโปรไฟล์ของคนๆ นั้น ตั้งแต่สาขาที่เรียน ระดับของมหาวิทยาลัย เกรดเฉลี่ย ไปจนถึงรายได้ที่เขาทำได้หลังจากเรียนจบมาแล้ว 10 ปี

## คอลัมน์ที่ใช้ในการทำนาย

ตัวแปรเหล่านี้คือปัจจัยและต้นทุนที่เกิดขึ้น "ก่อน" ที่บัณฑิตจะออกไปทำงานหาเงิน จึงเหมาะสมที่จะนำมาใช้เป็นตัวทำนาย:

- `major_category`: กลุ่มสาขาวิชาที่เรียน (เช่น STEM, Business, Arts, Social Science)
- `institution_selectivity_pctile`: เปอร์เซ็นไทล์ความยากในการสอบเข้ามหาวิทยาลัย (ยิ่งเยอะยิ่งสอบเข้ายาก)
- `gpa`: เกรดเฉลี่ยสะสม
- `had_internship`: ประสบการณ์ฝึกงาน (1 = เคย, 0 = ไม่เคย)
- `completed_on_time`: เรียนจบตามกำหนดเวลาหรือไม่ (1 = จบตามเกณฑ์, 0 = จบช้ากว่าเกณฑ์)
- `region`: ภูมิภาค
- `net_cost_usd`: ค่าเทอม/ต้นทุนการศึกษาสุทธิที่จ่ายไป
- `debt_usd`: หนี้สินสะสมเมื่อเรียนจบ

## คอลัมน์ที่ไม่ใช้ในการทำนาย

ตัวแปรกลุ่มนี้จะถูกตัดออกจากการเป็นตัวทำนาย (X) เนื่องจากบางตัวคือรหัสทั่วไป และบางตัวคือ "ผลลัพธ์" หรือเป็นตัวแปรที่นำไปคำนวณความคุ้มค่า ซึ่งเราไม่ได้นำมาเป็นเป้าหมาย (หากใส่ไปโมเดลจะถือว่าโกงข้อสอบหรือ Data Leakage):

- `grad_id`: รหัสประจำตัวบัณฑิต (ไม่ส่งผลต่อรายได้)
- `major`: สาขาวิชาเฉพาะ (ตัดออกเพื่อลดมิติข้อมูลที่ซ้ำซ้อน โดยใช้ `major_category` เป็นตัวแทนกลุ่มคณะแทน)
- `institution_tier`: ระดับของมหาวิทยาลัย (ตัดออกเนื่องจากเกิดปัญหา Multicollinearity ซ้ำซ้อนกับ `institution_selectivity_pctile` ซึ่งเป็นคะแนนละเอียดที่ถูกนำมาแบ่งเกรดเป็น tier)
- `net_roi_usd`: กำไรสุทธิ (ไม่ได้ใช้เป็นเป้าหมายหลักในโมเดลนี้ และมีความหมายทับซ้อนกับรายได้)
- `added_earnings_10yr_usd`: รายได้ส่วนเพิ่มจากการเรียนจบ (มีค่าความหมายเดียวกับรายได้)
- `hs_baseline_10yr_usd`: ฐานรายได้ถ้าเรียนจบแค่มัธยมปลาย
- `roi_pct`: เปอร์เซ็นต์ผลตอบแทนการลงทุน
- `positive_roi`: คุ้มทุนหรือไม่ (1 = คุ้ม, 0 = ขาดทุน)
- `high_roi`: ได้กำไรสูงมากหรือไม่
